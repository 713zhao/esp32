# assets

`ESP32-C6-LCD-1.9-factory.bin` (Waveshare factory demo firmware, flash at 0x0) is not committed
(vendor binary, git-ignored). Get it from the Waveshare demo package:

```bash
curl -LO https://files.waveshare.com/wiki/ESP32-C6-LCD-1.9/ESP32-C6-LCD-1.9-Demo-V2.zip
unzip -j ESP32-C6-LCD-1.9-Demo-V2.zip '*/Firmware/ESP32-C6-LCD-1.9-factory.bin' -d .
```
